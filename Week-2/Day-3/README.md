# 📘 DAY 3

## Amazon S3 — Simple Storage Service

Today, we learned about Amazon S3, an AWS object storage service used to store and retrieve files and other data. We explored buckets, objects, and several storage and access-management features.

## Important Concepts

- **Bucket:** A container used to organize and store objects in S3.
- **Object:** A file and its associated metadata stored in a bucket.
- **Region:** The AWS geographical region in which a bucket is created.

## Practical Work

We practised the following operations using Amazon S3:

1. Created an S3 bucket.
2. Uploaded objects to the bucket.
3. Downloaded stored objects.
4. Deleted objects when no longer required.
5. Explored bucket properties, permissions, and tags.
6. Learned about S3 object versioning.
7. Explored the settings required to allow public access to objects.

Public access must be configured carefully because it can expose stored data. Access should be granted only when required.

## Key Learnings

- Understood the difference between buckets and objects.
- Learned how to upload, download, and delete stored files.
- Explored bucket properties, tags, and versioning.
- Understood that access settings determine who can retrieve stored objects.

## Conclusion

This practical session introduced Amazon S3 and demonstrated how cloud object storage can be used to manage files securely and efficiently.
