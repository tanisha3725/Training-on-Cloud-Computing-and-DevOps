## Introduction to Docker

Today, we were introduced to Docker and learned how containerization helps package applications with their dependencies so they can run consistently across different environments.

## What Is Docker?

Docker is a platform for building, distributing, and running applications in containers.

Containers provide an isolated runtime environment for applications and help reduce differences between development, testing, and deployment systems.

## Docker Image vs Docker Container

- **Docker Image:** A template used to create containers.
- **Docker Container:** A running or stopped instance created from an image.

An image contains the files and configuration needed to create a container. A container uses that image to run an application or process.

## Important Docker Components

- **Docker Engine:** The technology responsible for building and running containers.
- **Docker CLI:** The command-line interface used to interact with Docker.
- **Docker Hub:** An online registry for sharing and downloading container images.

## Why Is Docker Useful?

Docker helps developers package an application and its dependencies into a consistent unit. This makes it easier to move applications between supported environments.
