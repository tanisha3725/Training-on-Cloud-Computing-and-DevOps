# 📘 DAY 1

## Introduction to Git and Version Control

Today, we learned about Git, a distributed version control system used to track changes in project files. We also discussed why version control is important in software development.

## What Is Version Control?

A Version Control System records changes made to files over time. It helps developers review project history, restore earlier versions, and work on changes without losing previous work.

Git allows developers to maintain repositories on their computers and synchronize their work with remote repositories.

## Basic Git Commands

| Command | Purpose |
|---|---|
| `git init` | Initializes a Git repository. |
| `git status` | Displays the current state of the working tree. |
| `git add .` | Stages changes in the current directory. |
| `git commit -m "message"` | Records staged changes. |
| `git remote add origin URL` | Adds a remote repository. |
| `git push -u origin main` | Pushes the main branch and sets its upstream. |
| `git pull` | Fetches and integrates remote changes. |

## Git vs GitHub

- **Git:** A version control tool that tracks changes.
- **GitHub:** An online platform for hosting Git repositories and collaborating with others.
