## Introduction to Jenkins

Today, we learned how Jenkins automates software development tasks and supports CI/CD workflows.

## What Is Jenkins?

Jenkins is an open-source automation server used to run tasks such as building applications, executing tests, and deploying software.

It can integrate with version control platforms such as GitHub to retrieve code and trigger configured workflows.

## GitHub and Jenkins Integration

A Jenkins job can retrieve source code from a GitHub repository and execute configured build steps. Depending on the setup, jobs can be 
triggered manually, periodically, or by repository events.

## Jenkins Job Types

### 1. Freestyle Project

A Freestyle Job is configured through the Jenkins interface. It can run commands, invoke tools, and perform configured build actions.

### 2. Pipeline Job

A Pipeline Job defines a sequence of stages and steps for automating a software delivery workflow.

## Why Use Jenkins?

Jenkins helps automate repetitive tasks, standardize workflows, provide build results, and make failures easier to identify.
