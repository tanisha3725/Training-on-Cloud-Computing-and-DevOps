## 🌍 Networking Fundamentals and Website Troubleshooting

Today, we explored common website errors, networking concepts, domain names, and the protocols used for communication between clients and web servers. We also learned about FTP accounts, WinSCP, and Vercel CLI.

## ⚠️ Common Website Errors

While accessing or deploying websites, different HTTP status codes may appear.

- **404 Not Found:** The requested webpage or resource could not be found on the server.
- **403 Forbidden:** The server understood the request but refused to provide access to the requested resource.

These errors can occur because of incorrect URLs, missing files, access restrictions, or server configuration issues.

## 🌐 DNS — Domain Name System

DNS stands for **Domain Name System**. It translates human-readable domain names into IP addresses that computers use to communicate over a network.

For example, when a user enters a website's domain name in a browser, DNS helps the browser locate the corresponding server.

## 🔒 HTTP, HTTPS and SSL

- **HTTP:** Hypertext Transfer Protocol, used for communication between web browsers and web servers.
- **HTTPS:** HTTP secured using encryption through TLS.
- **SSL:** Secure Sockets Layer, an older security protocol whose role has largely been replaced by TLS.

HTTPS helps protect information exchanged between the browser and the server against interception and tampering.

## 📂 FTP and WinSCP

FTP stands for **File Transfer Protocol**. It is used to transfer files between a client and a server.

An FTP account may include a username, password, server address, and access permissions. Such accounts can be used to give authorized people access to specific server files.

WinSCP is a file-transfer client for Windows that supports protocols such as SFTP and FTP. It can be used to connect to remote servers and transfer files.

**Security note:** SFTP is generally preferable to plain FTP when secure file transfer is required because it encrypts the connection.

## 🔎 Finding Pages Using Search Engines

We discussed searching for pages from a particular website or domain using search operators.

For example:

`site:example.in`

This asks a search engine to show indexed pages associated with the specified domain. The results depend on what the search engine has indexed.

## 💻 Vercel CLI

Vercel CLI is a command-line tool used to manage and deploy projects on Vercel.

It can be used for tasks such as linking a local project to a Vercel project, testing deployments, and deploying a website from the terminal.
